# Reading & favorites

MangaDex chapters, Web Sources chapters, local image directories, and image archives share the manga reader. PDF and EPUB use a [separate document reader](./local-library.md#pdf-and-epub-on-android).

## Show the reader controls

Tap the **center of the page** to show or hide the toolbar and progress controls. Use **Back** to leave the reader and return to the title or local library.

Use the progress control to jump to another page when **Progress Bar** is enabled. The reader displays the current page and total page count.

## Choose how pages move

Open **Reader Settings** <GuideIcon name="settings" /> in the reader toolbar.

| Setting | Use it for |
| --- | --- |
| **Single** | One page at a time, with horizontal page navigation. |
| **Long Strip** | Continuous vertical scrolling, useful for webtoons. |
| **Left to Right / Right to Left** | Page order in Single mode. Choose the direction that matches the manga. |
| **Swipe Gestures** | Allow swipe navigation in Single mode. |
| **Click/Tap to Turn Page** | Allow taps near the left or right edge to turn pages in Single mode. |
| **Toggle Page Size** | Change the page fit or displayed strip width. |

Edge taps follow the selected reading direction; do not assume the right side always advances. If a title is explicitly marked as long-strip content, its format control can be disabled. Direction and horizontal page-turn options are not used in Long Strip mode.

Reader preferences are saved as you change them. Start with the default page preload rather than setting it to the maximum: preloading is for smoother reading, not an offline download.

## Web Sources favorites

On a Web Sources title, tap the **heart / Add to Favorites** control. Check the categories where you want the title to appear. If you have no categories yet, use **Add New Category**, enter a name, and confirm; the title is added to that new category.

Open the Web Sources **Favorites** tab to find it again. Categories are local to Gagaku; you do not need a MangaDex account for them.

**History** can help you find previously browsed titles. The **Save History?** switch is on the Web Sources **History** screen. If you turn it off, new browsing entries will not be saved.

## MangaDex library

MangaDex's **Add to Library**, reading statuses, follow notifications, and account lists belong to your MangaDex account. They do not put a title in Web Sources Favorites or download its chapters.

If you want those account features, follow the [MangaDex login setup](./mangadex.md#sign-in-only-if-you-need-account-features).

::: info Saved does not mean offline
Favorites, library entries, history, and read markers keep track of titles and progress. They do not save the chapter files. Online sources still require connectivity; use your own local files for offline reading.
:::
